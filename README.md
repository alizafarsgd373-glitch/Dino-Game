# Dino Flight Game

A Java-based Dino game project developed as a programming project.

## About the Project

Dino Flight is a simple Java game featuring a dinosaur character and obstacles. The project demonstrates basic game programming concepts and object-oriented programming.

## Technologies Used

- Java
- Object-Oriented Programming (OOP)
- Java Classes and Objects

## Project Files

- `Dinoflight.java` — Main Java source file
- `Dinoflight$Dino.class` — Compiled Dino class
- `Dinoflight$Obstacle.class` — Compiled Obstacle class

## Features

- Dino character
- Obstacles
- Game-based interaction
- Java object-oriented structure

## How to Run

1. Install Java JDK.
2. Download or clone this repository.
3. Open `Dinoflight.java` in a Java IDE such as IntelliJ IDEA, Eclipse, or VS Code.
4. Compile and run the program.
